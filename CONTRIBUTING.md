# Contributing

Start with the README and research boundaries. Run:

```sh
python -m unittest discover -s tests -v
python -m ace_lab.run --out results/local-check --seeds 2 --steps 24
```

Use a new or empty output directory. Keep simulation evidence separate from real-model evidence. Report exact commands, seeds, model configuration and changes to assumptions when proposing experimental results.

Do not upload credentials, employer source code, customer records or production logs. Use fictional or appropriately licensed task data. For proposed research, describe the hypothesis and comparison baselines before changing evaluation code.
